## Вариант 10. Мониторинг реактора: давление на выходе

### Постановка задачи

Необходимо разработать программу для преобразования показаний датчика давления на выходе реактора X в величину технологического процесса Q.

Диапазон давления:

\(0.5 \le X \le 5\) бар

Преобразование выполняется по кусочной функции:

\(Q(X) =\)
• \(\frac{(X - 1.5)^2}{1} + 8\), при \(X < 1.5\)

• \(2 \cdot \sqrt{X - 2.5 + 2} + 42\), при \(1.5 \le X \le 3.5\)

• \(3 \cdot (X - 3.5) + 60\), при \(X > 3.5\)


Программа должна:

1. Получить значение давления \(X\).
2. Проверить принадлежность к диапазону штатного режима (\(1.5 \le X \le 3.5\) бар).
3. Рассчитать величину \(Q\) согласно условиям ветвления.
4. Вывести результат \(Q\).


### Контрольный пример

При:

X = 3.30 бар

результат:

Q = 45.35
